# V2-Custom-Media-Player-Mockup

This repository contains an interactive **UI/UX mockup** for a custom media player designed as part of an internship assignment for **V2 Indonesia**.

The project focuses on **interface layout, interaction design, and state-based behavior**, rather than full production media playback.

## Overview
The mockup explores how a custom media player could support:
- Single video playback
- Scheduled playlist playback
- Idle / attractor behavior for kiosk-style environments

All interactions, timelines, and scheduling logic are **simulated** to demonstrate user flow and system states.

## Scope
- Information architecture and state flows
- Gallery browsing and video playback UI
- Multi-select playlist scheduling flow
- Idle-to-active transitions

## Tech
- HTML
- CSS
- Vanilla JavaScript

Designed for a **1080 × 1920 display** and intended as a **high-fidelity interaction prototype**, not a production-ready player.
